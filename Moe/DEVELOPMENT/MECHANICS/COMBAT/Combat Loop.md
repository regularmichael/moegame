## **10. COMBAT FLOW SUMMARY**

### **Basic Combat Loop**

1. **Encounter Enemy** → Glyph visible but fuzzy
2. **Learn Glyph** → Focus 2 seconds (or 1 sec with psychometry)
3. **Equip Glyph** → Select from wheel menu
4. **Charge Glyph** → Focus on enemy (4 sec base, faster in ritual or with boost)
5. **Complete Glyph** → Enemy locks (5-second stun)
6. **Resolve** → Kill (get materials) or Release (get mana)

### **Advanced Combat Loop (Multi-Enemy)**

1. **Encounter 2-3 Enemies** → Multiple glyphs visible
2. **Deploy Ritual** → Place Chalice + consumable → light → choose item
3. **Passive Charging** → Ritual zones automatically charge matching glyphs
4. **Active Focus** → Manually focus priority targets (stacks with passive)
5. **Mana Lock** → Lock progress on one enemy, switch to another
6. **Juggle Targets** → Manage grace periods, avoid decay
7. **Complete Sequences** → Lock all enemies, choose resolutions
8. **Adapt** → Dismiss ritual if needed, use weapons directly

### **Panic Situation (Overwhelmed)**

1. **Surrounded** → Multiple enemies closing in
2. **Bell Shockwave** → 40 mana, knock all back, create space
3. **Place Ritual** → Quick Chalice + Wax (fast setup) + Incense (barrier)
4. **Recover** → Barrier buys 15 seconds, regenerate mana inside zone
5. **Re-engage** → Methodically complete glyphs one by one
