## **INVESTIGATION FLOW SUMMARY**

### **Basic Investigation Loop**

1. **Enter Area** → Look for interactive objects (prompt appears)
2. **Use Psychometry** → Touch object, watch vision (2-15 sec)
3. **Gain Clue** → Learn location, glyph, code, or story detail
4. **Follow Lead** → Go to revealed location
5. **Repeat** → Chain psychometry across 2-4 objects
6. **Solve Puzzle** → Final clue reveals solution (door code, hidden path, etc.)

### **Advanced Investigation (With Mandragora Risk)**

1. **Trigger Vision** → Deep read (10+ seconds)
2. **Monitor Feedback** → Audio cues intensify (whispers → footsteps)
3. **Risk Assessment** → "Do I need another read or is Mandragora too close?"
4. **Decision Point:**
    - **Continue:** Get more info, but Mandragora spawns
    - **Stop:** Incomplete info, but safe from Mandragora
5. **Escape if Needed** → If Mandragora spawns, flee to safe room
