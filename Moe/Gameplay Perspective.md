# **Perspective 1: Third person, over the shoulder**

*In the style of:* RE Remakes, Alan Wake 2, Silent Hill 2 Remake, Hellblade
![[Pasted image 20241220212758.png]]
![[Pasted image 20241220213046.png]]
This has been shown to be a consistently strong choice for "prestige" horror games, especially those with a focus on combat. Over-the-shoulder perspectives have a lot going for them - they necessarily limit how far behind the character the player can see, so you can do a lot of good spoopy stuff. For combat, having a full view like this is good for intuitive and meaty combat.

This would probably be a better choice for games 2/3. I don't feel strongly in my  current technical skills to make the best use of this approach. However, I think it'd be the best choice for bringing the Haze to life. (The first person perspective would also work well, but I don't think I like that perspective for this game series.)

I think what will really make or break this perspective is how much emphasis we put on combat, and the kind of combat therein. I still need to figure out what combat fully looks like - how do we make it fit ludnarratively with Moe's "there's always anothey way" dictum? That part's a question for another document, but for this, the important thing to state is that if combat is a huge element of gameplay, then this perspective gains some favor. Otherwise, there's not much this perspective can offer that won't already be covered well by other perspectives.

I also see this perspective being an issue for controlling Midnight. Again, this will need to be addressed with combat design (or lack of combat design, depending.) If we want controlling midnight to be more in the hands of the player than an AI controller, then I think naturally players would want Midnight to watch their back - but that's hard to do if you can't actually see too far behind Moe. Additionally, if you can only command in the line of sight for Moe, then how do you compromise making Midnight feel like her own entity that contributes to the world, rather than just another tool for the player to use?

Overall, I'm not willing to fully commit to this perspective, at least not for the first game. Depending on the skill sets that people bring to this game, I think another perspective would better fit our needs so we can test our designs and take advantage of the massive benefits this perspective offers to people who know how to use it. 

**Pros**
- Well established
- Limited perspective allows for a more cerebral approach to gameplay
- Great for the Haze  
- Amenable to combat
- Friendly to cinematic/gameplay transitions
- Can show the world in great detail

**Cons**
* Kinda saturated - a lot of games using this feel similar
* More complicated development
* Requires precision in combat
* Enemy models will require a LOT of work
* Harder for best Midnight control probably
